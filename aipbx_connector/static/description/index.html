AiPBX Connector

Your AiPBX phone system inside Odoo

Connects Odoo to an AiPBX phone system (open source, Asterisk based). Calls go through the PBX as always; Odoo learns about them and can start them. If Odoo is down, nobody's phone stops working.

  • Click-to-call: the Call button next to a contact's phone rings your own phone (desk phone, web phone or app), then dials the number.
  • Caller pop-up: when a call rings at your extension - directly, from a queue or a ring group - Odoo shows who is calling, with the contact one click away. Only the user whose phone rings sees it.
  • Call log: one record per call, however many phones rang: direction, who answered, wait and talk time, outcome (answered, missed, gave up in the queue).
  • Chatter: one line per call on the contact; the recording is played through Odoo for users allowed to see the call. Recordings stay on the PBX.
  • Missed calls from known contacts become a call-back activity.
  • AI summary: when the PBX analyses the call, the summary and the quality score are added to the contact (and the call).
  • CRM: with the CRM app, calls also land on the contact's open opportunity (the AiPBX Connector - CRM part installs by itself).
  • Contacts to the PBX (optional): desk phones show the caller's name from Odoo.

Setup

  1. In Odoo: AiPBX > Configuration > Connections > New. Save it.
  2. On the PBX: Integration > Connections > New connection, kind Odoo, with this Odoo's address.
  3. Copy the connection pack the PBX shows and paste it in Odoo (Paste connection pack). The extensions come in; users are matched by e-mail, the rest you choose.

Security

  • Each connection has its own PBX key with only the rights a CRM needs, and its own webhook secret. Both are stored encrypted; set aipbx_secret_key in the Odoo configuration file to keep the encryption key outside the database.
  • Every event from the PBX is signed (HMAC-SHA256 with a timestamp) and stored once; a repeated delivery is not processed twice.
  • The browser never gets the PBX key. Click-to-call uses the extension assigned to the signed-in user, not a value from the browser.

Requires AiPBX with Integration > Connections. Self-hosted Odoo or Odoo.sh (Odoo Online cannot install apps from the store). Source and issues: github.com/mahirgul/AiPBX-Odoo.
